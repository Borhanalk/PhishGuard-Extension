# PhishGuard – Chrome Extension

PhishGuard is a cybersecurity-focused Chrome Extension designed to detect and warn users about potential phishing websites in real-time.

This project was developed as part of practical cybersecurity training, focusing on browser security, phishing detection techniques, and client-side threat analysis.

---

## Overview

Phishing remains one of the most common attack vectors in modern cyber threats.  
PhishGuard demonstrates how browser-based detection logic can identify suspicious URLs and warn users before they interact with malicious content.

The extension analyzes website URLs and applies predefined security rules to detect potential phishing indicators.

---

## Features

- Real-time URL inspection
- Suspicious keyword detection
- Domain structure validation
- Detection of misleading subdomains
- Visual warning alerts for unsafe websites
- Lightweight and fast performance

---

## Detection Logic

PhishGuard analyzes:

- Suspicious domain formatting
- Presence of phishing-related keywords (login, verify, secure, update, account, etc.)
- URL obfuscation patterns
- Use of fake or deceptive subdomains
- Indicators of impersonation techniques

The goal is to simulate basic phishing detection strategies commonly used in Security Operations Centers (SOC).

## Installation (Developer Mode)

1. Clone the repository:

   git clone https://github.com/Borhanalk/PhishGuard-Extension.git

2. Open Chrome and navigate to:

   chrome://extensions

3. Enable Developer Mode.
4. Click "Load unpacked".
5. Select the project folder.
